# Maintenance Ledger

This on-demand ledger preserves versioned observations, investigation history, deferred work, and watch items for EyrAgents.

Read this file before a tool or plugin major-version upgrade, permission changes, reviewer-bridge changes, cross-host validation, `/doctor`, or work on a deferred item. Current repository invariants remain in `AGENTS.md`; canonical managed cross-tool policy remains in `claude-code/.claude/rules/shared-guidance.md`. Dated client versions are historical evidence, not synchronization targets; routine releases require no ledger edit. Re-fetch affected facts when a relevant interface, behavior, major version, or configuration changes.
