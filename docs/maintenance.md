# Maintenance Ledger

This on-demand ledger preserves versioned observations, investigation history, deferred work, and watch items for EyrAgents.

Read this file before a tool or plugin major-version upgrade, permission changes, reviewer-bridge changes, cross-host validation, `/doctor`, or work on a deferred item. Current repository invariants remain in `AGENTS.md`; canonical managed cross-tool policy remains in `claude-code/.claude/rules/shared-guidance.md`. Dated client versions are historical evidence, not synchronization targets; routine releases require no ledger edit. Re-fetch affected facts when a relevant interface, behavior, major version, or configuration changes.

- publication-review decision 2026-08-30: the managed `/commit` workflow screens each exact candidate against its intended audience before commit, then reviews all metadata and artifacts the bound publication descriptor would expose before any publication-ready claim or push hint. Path and object metadata are inventoried before content, Safety-barred or opaque artifacts remain unread, H inspects those artifacts in a separate terminal pane without `!` and rules on exact path/object pairs, and all records reconcile to reviewed content, a ruling, or a blocker. Endpoint credentials never enter the descriptor, and transient authenticated transfer URLs remain opaque transport data. Code review and secret scanning remain separate. GitHub documents that rewritten commits may remain accessible in clones, forks, cached views, and pull-request references: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository.
